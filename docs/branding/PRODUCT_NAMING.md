# Peecool: Product naming record

**Recommended and selected name: Peecool** (PEE-cool). Proposed by the project owner after the first recommendation, **Ralvo**, turned out to be an existing app. It then passed more checks than any other candidate. This is **not legal clearance**; see "Open concerns".

## Method (and its limits)
1. Generated coined and descriptive candidates around rally, court, serve, volley, dink, bounce and composure.
2. **App Store check:** Apple's public iTunes Search API (US storefront), counting results whose app name or seller contains the candidate. Validated first: it finds both *Ralvo* (published by KAI R&D LTD) and *Sevra* (a personal-trainer app).
3. **Domain check:** `.com` and `.net` against Verisign's RDAP (authoritative); `.app`, `.io`, `.ph` against the public RDAP bootstrap (patchy for some TLDs).
4. **Web search** for existing businesses and products.
5. **Why three layers:** general web search *missed* Ralvo even though it exists, so web search alone is not trusted.
6. **Not checked:** Google Play (no public API), Microsoft Store, social handles, trademark registers (USPTO, EUIPO, IPOPHL), other countries' app stores. Checks run on 2026-11-01.

Evaluation criteria: memorability, pronunciation, uniqueness, visual-identity potential, long-term flexibility, domain potential, and Filipino/English suitability (the vendor is in Bacolod; pricing is in PHP).

## Top three
1. **Peecool.** Only candidate with a free `.com` and no App Store match.
2. **Dovra.** Cleanest of the coined names; no meaning to build on.
3. **Vollo.** Best sport link; closeness to Volo Sports is a risk.

## Recommendation
**Peecool**, because it is the only candidate that cleared every check that could be run and it carries a meaning (P + cool) that supports the tagline and the personality. Its weakness is tone, not availability.

## Open concerns
- **The "pee" reading.** Expect jokes; some buyers may find it too casual for a business product. Mitigation is built into the identity (serious green palette, bold tabular numerals, checkmark symbol, tagline built on "cool", facility's own name leads). **Test with two or three real facility owners before committing to signage, print or a domain purchase.** If it fails that test, Dovra is the fallback and every asset can be regenerated from `docs/branding/source/`.
- Native Filipino speaker should check for unintended meanings.
- Formal trademark search by counsel (USPTO, EUIPO, IPOPHL), covering software and sports-service classes: **not done**.
- Domains: register peecool.com and peecool.net promptly if approved; confirm .app, .io, .ph with a registrar.
- Google Play, Microsoft Store and social handles: not checked.
