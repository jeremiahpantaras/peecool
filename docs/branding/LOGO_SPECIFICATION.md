# Peecool: Logo specification

All assets live in `apps/web/public/brand/` (served at `/brand/*` by the existing static handler; nothing references them yet). They are generated by `docs/branding/source/build-logos.mjs`, which reproduces every SVG byte-for-byte. The wordmark is **outlined to paths** (no `<text>`, no font dependency); there are no filters, gradients, masks or raster images.

## Concept: "The Bounce"
A pickleball's bounce is the sport's signature moment (the two-bounce rule, the serve return, the point). The symbol draws that path:
1. **Motion trail**: a tapered arm coming down, thin at the top like a ball in flight.
2. **Impact**: the arms meet in a flat-bottomed vertex that sits just above the court line.
3. **Launch**: a constant-width arm rises to a **perforated ball** (a gap separates it from the arm, as if just struck).
4. **Court line**: a rounded rule under the symbol; the wordmark stands on the same line.

It also reads as a **check mark** (a point confirmed) and an upward trend. It is original artwork; there is no stock icon or generic ball-plus-label pairing. It was compared with the reference page's lowercase serif wordmark and shares nothing with it (uppercase condensed sans wordmark, geometric symbol).

## Geometry (symbol grid 120 × 120)
| Part | Value |
|---|---|
| Trail top (centre-line) | (8, 14), width 3 |
| Vertex | (50, 92), width 24, flat cut at y = 98 |
| Arm end | (88, 46), width 24 |
| Ball | r = 16, gap 4 from the arm end, along the arm direction |
| Perforations | 1 centre + 6 on a ring of radius 8.6 (phase 0.3 rad), hole r = 2.1 |
| Ball ring (colour variants on light) | stroke 2.6 |
| Court line | x 6–114, y 104–110, radius 3 |
| Wordmark | Letterforms outlined from Barlow Condensed 800 (artwork only; **not** part of the type system, which is Geist), cap height 58 units, tracking 3.2, baseline y = 98, 12 units after the symbol |

## Clear space
The **ball's diameter** (32 of 120 units, about 27% of logo height) on every side of any lockup.

## Minimum size
| Version | Digital | Print |
|---|---|---|
| Horizontal | 120 px wide (34 px tall; wordmark cap 16.5 px, ball about 9 px) | 30 mm |
| Stacked | 80 px wide | 22 mm |
| Symbol | 32 px | 8 mm |
| Favicon form | 16 px | n/a |

Below a minimum, change version (horizontal → symbol → favicon) instead of shrinking.

## Colour and background usage
| Background | Version |
|---|---|
| Cream #F8FFEF, white, mint #E8F4E7 | Primary |
| Court green #0D3F27, #082015, #06150D | Light |
| Rally lime #C4E94A, sage #CBD9C9 | Dark (ink) |
| Photography | Light on a dark overlay giving ≥ 4.5:1 behind the wordmark; otherwise monochrome |
| Anything else | Monochrome, in ink or cream, whichever contrasts ≥ 4.5:1 |

Never: stretch, rotate, recolour off-palette, place the primary (green and lime) on lime, add shadows or outlines, rearrange the parts, retype the name, or put anything inside the clear space. In running text write **Peecool** (capital P only); the all-caps form exists only inside the logo. Never abbreviate to "PC" (it collides with "Master PC").

## Regenerating
```bash
cd docs/branding/source
npm install            # opentype.js and wawoff2; local to this folder, not the app
node build-logos.mjs ../../../apps/web/public/brand
```
`geom.mjs` holds the symbol, `logos.mjs` the variants, `palette.mjs`/`contrast.mjs` the colours and the contrast check (`node contrast.mjs`). PNG exports were produced by rendering the SVGs in headless Chromium at 180, 192, 512 and 32/48 px.
